# Bellonis Place - React Application

A modern, responsive React + TypeScript + Tailwind CSS web application for **Bellonis Place**, an eatery located at Ekiti State University (EKSU), Faculty of Engineering.

## Features

- **Hero Slider**: Auto-advancing (5-second interval) image carousel highlighting signature dishes (Ewa Agoyin, Spaghetti Special, Jollof Rice, and Fried Rice) with interactive controls and pause-on-hover.
- **Dynamic Menu Catalog**: Categorized dish browsing across Mains, Swallows, Proteins, and Chilled Drinks with live keyword search and instant pricing in Naira (₦).
- **Interactive Ordering System**:
  - Live order cart drawer with real-time quantity adjustments and subtotal tracking.
  - Campus delivery and pickup options (Faculty of Engineering counter pickup, Dine-in, or Campus hostel delivery).
  - Special meal notes and pepper instructions.
  - Instant digital order receipt modal with one-click direct dispatch to Bellonis Place on WhatsApp (`+2347069248829`).
- **Interactive Food Gallery**: High-resolution image showcase with an interactive modal lightbox.
- **Direct Contact & Inquiries**: Campus location details, direct call (`+2347069248829`), WhatsApp chat, email (`eaterybellonisplace.com`), operating hours, and message submission.
- **Responsive Design**: Mobile-friendly layout styled with Tailwind CSS, preserving the original brand coral color (`#ff6f61`) and typography.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
